# Motor Theft SQL Analysis Showcase

This folder contains SQL analysis scripts for the motor theft project.

## Files
- 01_exploratory_summary.sql: overall theft overview and key metrics
- 02_region_analysis.sql: theft activity by region and country
- 03_time_series_analysis.sql: monthly and weekday theft trend analysis
- 04_make_and_vehicle_profile.sql: make-level and vehicle characteristic analysis
- 05_risk_insights.sql: population-adjusted risk ranking by region

## Usage
Run these queries against the MySQL tables created from the processed CSV files:
- locations
- make_details
- stolen_vehicles

These scripts are intended to be used as project-demo SQL experiments for portfolio or presentation purposes.
